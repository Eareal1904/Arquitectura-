* Objetivos de Aprendizaje

- Definir el concepto de Máquina Virtual (VM) y el rol del Hipervisor.
- Diferenciar arquitecturas de virtualización Tipo 1 y Tipo 2.
- Conocer los beneficios de la virtualización de hardware.

* Notas de Cornell

#+attr_latex: :environment longtable :align |p{4.5cm}|p{10.5cm}|
| *Ideas Clave / Preguntas* | *Apuntes de Clase*                                                                                                   |
|---------------------------+----------------------------------------------------------------------------------------------------------------------|
| *Máquina Virtual (VM)*    | Entorno de software aislado que emula un sistema físico completo con su propio Sistema Operativo (Guest OS).         |
| *Hipervisor (VMM)*        | Monitor de Máquinas Virtuales. Capa de software que abstrae, divide y asigna el hardware real a las VM.              |
| *Tipo 1 (Bare Metal)*     | El hipervisor se instala directamente sobre el hardware físico, sin SO intermediario. Muy rápido y eficiente.        |
| *Tipo 2 (Hosted)*         | El hipervisor se instala como un programa más sobre un Sistema Operativo anfitrión (Host OS). Genera mayor latencia. |
| *Beneficios*              | Aislamiento de fallos, seguridad, portabilidad de entornos y consolidación de servidores físicos.                    |

* Resumen
Las Máquinas Virtuales permiten abstraer el hardware de una
computadora gracias al Hipervisor (VMM). Los de Tipo 1 operan directo
en el hardware ofreciendo máximo rendimiento para servidores, mientras
que los de Tipo 2 corren sobre un SO anfitrión, siendo ideales para
entornos de desarrollo y pruebas de escritorio.
