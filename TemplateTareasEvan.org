* Objetivos de Aprendizaje

- Entender cómo una dirección virtual se convierte en una dirección
  física en RAM.
- Identificar la estructura de una dirección paginada (página +
  desplazamiento).
- Comprender el uso de la Tabla de Páginas.

* Notas de Cornell

#+attr_latex: :environment longtable :align |p{4.5cm}|p{10.5cm}|
| *Ideas Clave / Preguntas* | *Apuntes de Clase*                                                                                   |
|---------------------------+------------------------------------------------------------------------------------------------------|
| *Dirección Lógica*        | Generada por la CPU. Se divide en Número de Página ($p$) y Desplazamiento ($d$).                     |
| *Número de Página ($p$)*  | Sirve como índice para buscar en la Tabla de Páginas.                                                |
| *Desplazamiento ($d$)*    | Ubicación exacta del byte dentro de la página. *No se altera* al traducir a dirección física.        |
| *Tabla de Páginas*        | Estructura que indica en qué Marco Físico ($f$) está guardada cada Página Virtual ($p$).             |
| *Dirección Física*        | Se forma combinando el Marco Físico ($f$) extraído de la tabla con el Desplazamiento original ($d$). |
| *MMU*                     | Unidad de Gestión de Memoria. Es el hardware de la CPU que hace esta traducción en tiempo real.      |

* Resumen
La traducción de direcciones es un proceso de hardware gestionado por
la MMU. La dirección virtual se parte en dos: el número de página
busca el marco en la tabla de páginas, y el desplazamiento se mantiene
igual. Al concatenar el marco con el desplazamiento, se obtiene la
dirección física exacta en la memoria RAM.
