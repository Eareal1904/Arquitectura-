\section{Taller: Máquina de Von Neumann}
\label{sec:org84104a5}

La máquina de Von Neumann realiza operaciones en un ciclo repetitivo de
\textbf{captación}, \textbf{decodificación} y \textbf{ejecución}. Para esto, el computador
IAS usa una memoria de 40 bits. Cuando la memoria se usa
numéricamente, el dato representa un número en complemento a 2; donde
el bit inicial corresponde al signo. Cuando la memoria se usa para el
registro de instrucciones, se divide en dos partes de 20 bits cada una. Los 8
primeros bits de cada parte corresponden al \emph{opcode} y los restantes
12 bits de cada parte a la \emph{dirección (operando)} desde la que se debe
leer o a la que se debe escribir.

\subsection{Ejercicio}
\label{sec:orgb98224b}

En la máquina IAS, las instrucciones se dividen en dos segmentos:
i) izquierdo, desde el bit 0 a 19, y ii) derecho, desde el bit 20 al 39. Primero
se ejecuta el lado izquierdo y luego el derecho. El
contador de programa inicia en la posición \([PC] \leftarrow 300\). El conjunto de
instrucciones del computador o ISA\footnote{Instruction Set Architecture: conjunto de instrucciones que la máquina IAS puede interpretar y ejecutar.} está definido en la Tabla
\ref{tab:tablaISA-IAS}. A fin de terminar el programa, se agrega la
instrucción \texttt{0x99} que lleva al computador al estado de HALT. Conteste las
siguientes preguntas considerando la Tabla \ref{tab:org2f87291} como el
mapa de memoria de la máquina y obtenga el programa en lenguaje ensamblador y en
RTL.

\subsubsection{Código RTL}
\label{sec:orgc6e8743}
Escriba en notación de transferencia de registros el programa que ejecuta el computador IAS.

A continuación se detalla el ciclo completo de captación (Fetch), decodificación y ejecución de la CPU paso a paso:

\begin{verbatim}
[Dirección 0x300 - Instrucción Izquierda]
1.  [PC] <- 0x300
2.  [IR] <- [[PC]]
3.  [IR] <- [0x300]
4.  [IR] <- 01 940     ; Decodifica Opcode 01 (LOAD) y dirección 940
5.  [AC] <- [940]
6.  [AC] <- 5

[Dirección 0x300 - Instrucción Derecha]
7.  [IR] <- 06 941     ; Decodifica Opcode 06 (SUB) y dirección 941
8.  [AC] <- [AC] - [941]
9.  [AC] <- 5 - 2
10. [AC] <- 3

------------------------------------------------------------------------

[Dirección 0x301 - Instrucción Izquierda]
11. [PC] <- 0x301
12. [IR] <- [[PC]]
13. [IR] <- [0x301]
14. [IR] <- 21 940     ; Decodifica Opcode 21 (STOR) y dirección 940
15. [940] <- [AC]
16. [940] <- 3         ; Se sobrescribe la localidad 940 con el valor 3

[Dirección 0x301 - Instrucción Derecha]
17. [IR] <- 14 000     ; Decodifica Opcode 14 (LSH)
18. [AC] <- [AC] x 2
19. [AC] <- 3 x 2
20. [AC] <- 6

------------------------------------------------------------------------

[Dirección 0x302 - Instrucción Izquierda]
21. [PC] <- 0x302
22. [IR] <- [[PC]]
23. [IR] <- [0x302]
24. [IR] <- 21 941     ; Decodifica Opcode 21 (STOR) y dirección 941
25. [941] <- [AC]
26. [941] <- 6         ; Se sobrescribe la localidad 941 con el valor 6

[Dirección 0x302 - Instrucción Derecha]
27. [IR] <- 02 940     ; Decodifica Opcode 02 (LOAD -M(X)) y dirección 940
28. [AC] <- -[940]
29. [AC] <- -3         ; Carga el valor actual de 940 con signo invertido

------------------------------------------------------------------------

[Dirección 0x303 - Instrucción Izquierda]
30. [PC] <- 0x303
31. [IR] <- [[PC]]
32. [IR] <- [0x303]
33. [IR] <- 21 940     ; Decodifica Opcode 21 (STOR) y dirección 940
34. [940] <- [AC]
35. [940] <- -3        ; Se guarda el valor final -3 en la localidad 940

[Dirección 0x303 - Instrucción Derecha]
36. [IR] <- 99 000     ; Decodifica Opcode 99 (HALT)
37. [IR] <- HALT       ; La máquina detiene su ejecución de forma definitiva
\end{verbatim}

\subsubsection{Preguntas}
\label{sec:org8fb2990}

\begin{enumerate}
\item ¿Qué resultado se tiene al final en el registro del acumulador?

Respuesta:
\([AC] \leftarrow -3\)

\item ¿Se sobrescribe algún registro como resultado de la ejecución? Si
es verdadero, indique qué registro y con qué valor.
Respuesta:
\begin{itemize}
\item \([940] \leftarrow -3\)
\item \([941] \leftarrow 6\)
\item \([AC] \leftarrow -3\)
\end{itemize}

\item ¿Cuál es el valor del bit de Carry? ¿Qué operación modifica el bit?
Respuesta:
\begin{itemize}
\item \(Carry = 0\)

\item Dos operaciones modifican este bit, primero la suma la cual hace
que el carry tome el valor de 1, luego el LSH con el
desplazamiento hace que el carry tome el valor de 0.
\end{itemize}
\end{enumerate}

\end{enumerate}
